# WebGL Creations Portfolio 🎨✨

A beautiful, high-performance portfolio featuring interactive WebGL mathematical models, particle simulations, real-time shaders, and audio-reactive environments.

## 🚀 Projects Included

This portfolio hosts several WebGL experiences:

1. **Heart** - A pulsating mathematical heart formed by glowing particles, adjusting to live settings.
2. **Music Terrain** - A stunning, audio-reactive landscape generated using Perlin noise.
3. **Christmas Tree** - A mathematical spiral formation of light and snow particles.
4. **Volumetric Clouds** - Color-shifting clouds rendered using raymarching.
5. **Cel Shader** - Real-time cel shading with stylized outline and lighting effects on 3D models.

---

## 🛠️ Tech Stack & Libraries

- **Three.js** (WebGL 3D library)
- **Vite** (Next-generation frontend tooling)
- **TypeScript** & **JavaScript**
- **Custom GLSL Shaders** (Vertex & Fragment)
- **GitHub Pages** (Automated continuous deployment via Actions)

## 📦 Getting Started & Local Development

To run the portfolio or any of the sub-projects locally:

### 1. Clone the repository
```bash
git clone https://github.com/chicanancom/chicanancom.github.io.git
cd chicanancom.github.io
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
To run the main portfolio landing page:
```bash
npm run serve
```
To run all workspaces/sub-projects in development mode:
```bash
npm run dev
```

### 4. Build projects
To build all projects for production:
```bash
npm run build
```
